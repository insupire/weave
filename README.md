# weave

분석뷰를 선언하는 스키마와 그것을 그리는 참조 구현. **보험을 모른다.**

- 설명서를 보려면 → [`viewer.html`](viewer.html) 을 브라우저로 연다 (서버도 설치도 없다). primitive element 를 하나씩 보고, 목차 끝의 플레이그라운드에서 직접 고쳐 본다
- 스키마를 쓰거나 값을 채운다면 → [`docs/weave.md`](docs/weave.md)
- 그린다면 → 지킬 것은 [`docs/weave.md` §렌더가 하기로 돼 있는 것](docs/weave.md#렌더가-하기로-돼-있는-것), 본보기는 참조 렌더 [`render/`](render) 하나다
- 이 저장소를 고친다면 → [`AGENTS.md`](AGENTS.md)
